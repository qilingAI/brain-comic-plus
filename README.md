# 脑洞动画工厂 Plus

一个制作「上方文字、下方动画」竖屏短视频的 Agent Skill。

先分析主题、写完整底稿，再提炼几行短文案，从中挑一个精彩片段演成动画。视频与声音一次生成，最后用 FFmpeg 排字、配乐，输出完整竖屏视频。

默认画风：**手绘动画风格、上美影风格、中国学派、复古手绘二维动画、工笔重彩、京剧元素**。

## 安装与使用

把仓库放进支持 `SKILL.md` 的 Agent 技能目录。以本地 Codex 技能目录为例：

```sh
git clone https://github.com/qilingAI/brain-comic-plus.git ~/.codex/skills/brain-comic-plus
```

已有同名目录时先确认它的用途，不覆盖现有文件。技能入口为 [SKILL.md](SKILL.md)。

可以这样发起：

```text
使用 $brain-comic-plus，主题是「朱元璋为什么要杀蓝玉？」。
先做第一步，暂时不要生成视频。
```

```text
根据第一步资料生成分镜提示词，先不要调用视频接口。
```

```text
我要自己把提示词发给豆包生成视频，下载后再继续后期。
```

```text
视频已放进约定的「用户视频」目录，继续检查并合成竖屏成片。
```

默认逐阶段调试；明确要求一次完成全流程时，才连续执行各阶段。

## 三步流程

### 1. 主题分析、完整底稿、短文案与精彩片段

先查清主题中的事实、人物处境、事件变化与结果，再写连贯底稿，最后提炼上方显示的短文案。底稿不受 10 秒片长限制。

- 上屏默认约 5–6 行、40–60 字，直接陈述事件、经过与结果。
- 不加作者观点、动机评论、设问或总结句。
- 动画只演一个精彩片段，不逐句演完整底稿。
- 事实依据和演绎边界保存在制作记录中。

示例文字：

```text
洪武二十一年
蓝玉北征大胜归来
夜叩喜峰关，关吏未及时开门
他纵兵毁关而入
五年后，蓝玉遭谋反指控
被朱元璋处死
```

### 2. 分镜提示词与获取视频

直接编写人物、场景、动作、表情、运镜和声音，不先提取资产或生成设定图。整条视频一次生成；可以有内部切镜、人物介绍与对白，**有对白就配对应字幕**，旁白一般不需要。

视频提示词只描述本条视频内容。尺寸参数、最终上下布局、FFmpeg 操作与 BGM 库不混进模型提示词，也不自动追加通用禁止清单。

| 获取方式 | 模型／来源 | 默认设置 |
| --- | --- | --- |
| 器灵接口 | `doubao-seedance-2.0-mini` | 10 秒、480p、1:1，开启声音生成 |
| 宿主内置 `videogen` | `seedance-2.0-fast` | 10 秒、1:1；工具支持时尝试 720p |
| 用户手动生成 | 豆包等用户选择的工具 | 交付提示词，建议 10 秒、480p、1:1，之后读取本地视频 |

用户指定获取方式时按其要求执行。未指定且要求实际生成时，依次检查：**已有 API Key → 实际可调用的内置 videogen → 手动生成接续**。

没有 API Key 不会直接阻塞工作，也不强制先申请 Key。内置工具是否存在、支持哪些参数，以当前 Agent 实际工具说明为准；没有分辨率字段时，不强塞 `resolution` 参数。宿主内置工具由 Agent 调用，Python 脚本不会凭空创建这项能力。

异步生成保存真实任务标识，后续查询同一个任务；结果不明时不重新提交。已有接口任务不会因缺失 Key 被自动转投另一通道。

### 3. FFmpeg 排字、配乐与合成

取得实际可读取的视频文件后，检查内容、尺寸、时长、音轨和字幕，再制作完整竖屏成片。

- 最终画布默认 **1080×1920，9:16**。
- 视频按原比例铺满宽度，左右不留边；剩余高度给文字，不强制五五分。
- 1:1 素材显示为 1080×1080，上方文字区为 1080×840。
- 上方文字整段同时显示；每行只去掉末尾一个逗号或句号，保留问号、叹号和行内标点，原文稿不变。
- 保留视频原声，BGM 按需混入；后期不再次调用视频模型。

## BGM 库与手动视频目录

在**创作项目根目录**建立 `bgm/`，放入可用音源。它不必放在技能仓库中。

BGM 优先级：用户指定文件 → 用户指定曲库 → 当前项目 `bgm/`。没有可用 BGM 就不加，仍可完成视频。保留对白与动作音效，不把混合音轨直接静音来去掉音乐。

手动生成的视频可以放在任意明确指定目录；默认建议：

```text
data/创作记录/<中文主题名>/用户视频/
```

放好后告诉 Agent 继续。它会沿用既有文稿与提示词，检查真实视频并接续后期，不要求器灵授权或重新生成。多份视频无法判断采用哪份时才需要选择。原视频保持原处，素材记录引用真实路径与哈希，不额外复制大文件。

## 文件组织

```text
创作项目/
├── bgm/                              # 用户音源库，可选
├── creations/<中文主题名>/
│   └── 文字图层/                     # 排字需要的图片
└── data/创作记录/<中文主题名>/
    ├── 主题分析.md
    ├── 完整底稿.md
    ├── 故事文稿.md                    # 短文案与精彩片段
    ├── 分镜提示词.md
    ├── 分镜提示词.json
    ├── 视频任务/                      # 接口或内置工具任务记录
    ├── 用户视频/                      # 手动生成后投放
    ├── 视频片段/                      # 接口结果下载
    ├── 视频素材.json
    └── 视频成片/
```

每次新创作使用中文主题目录；重新创作保留独立版本。图片与文案、记录分开存放，默认不生成 ZIP。调试规则时只改技能，验证时重新运行并保留旧产物对照，不手工改好一份成片就声称规则有效。

## 环境与脚本

这是由 Agent 执行的技能，不是一个命令自动完成所有步骤的应用。后期需要本地 **FFmpeg / ffprobe** 和可用的中文字体；排字及可选参考图检查使用 Pillow。接口脚本需要 Python 3.10+。

器灵接口按需使用官方 `qiling-ai-sdk 0.5.4` 与系统 `keyring`；安装与授权步骤见 [器灵接口说明](references/qiling-video.md)。只用内置工具或手动视频时，无需器灵 SDK 或 API Key。密钥放系统凭据库或本地环境变量，不写入提示词和普通配置。

以下命令在技能仓库目录中执行，`python` 换成当前可用解释器：

```sh
# 仅查看非敏感接口配置
python scripts/qiling_video.py config

# 用户选择器灵授权时，再由用户本人在浏览器确认
python scripts/qiling_video.py authorize

# 读取当前账户可用模型资料
python scripts/qiling_video.py models

# 实际提交一次，重跑时查询原任务或恢复下载
python scripts/qiling_video.py run --storyboard /实际路径/分镜提示词.json --id shot-01

# 只恢复已存在的任务
python scripts/qiling_video.py sync --storyboard /实际路径/分镜提示词.json --id shot-01
```

`run` 可能提交付费生成任务，只在确实需要生成时执行。无 Key 的新任务会返回宿主工具检查计划；这不是已经提交或已经生成成功。FFmpeg 合成由 Agent 按后期规则执行，`delivery_layout.py` 提供满宽布局和显示标点处理函数。

配置见 [qiling-video.json](references/qiling-video.json)：`generation_defaults` 用于接口与手动交接，`builtin_videogen` 用于宿主内置工具。画风见 [styles.json](references/styles.json)。
